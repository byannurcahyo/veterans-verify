## Verification Flow (Updated 2025-12-24)

```
1. Create temporary email
2. Open chatgpt.com/veterans-claim
3. Click "Log in" → Register/Login ChatGPT
   - Enter email → Create password (new user)
   - Receive ChatGPT email code → Enter code
4. Automatically enter SheerID form after login
5. Fill form (Branch, Name, DOB, Discharge Date, Email)
6. Click "Verify My Eligibility"
7. **Receive SheerID verification email** (From verify@sheerid.com, contains link!)
8. Click link to complete verification
9. Success → Redirect to chatgpt.com (Account gets 1 year Plus)
```

**Key Findings:**
- SheerID page requires ChatGPT login first to access
- Will receive two emails: ChatGPT verification code + SheerID verification link

## ⚠️ Mandatory Rules

### 1. Anti-Detection Strategy
```
Browser Layer (Camoufox advantages):
- Firefox C++ level modification (Not JS injection)
- 0% headless detection rate (vs Patchright 67%)
- Full fingerprint spoofing (navigator, screen, WebGL, canvas, audio etc.)
- Built-in human cursor movement algorithm
- GeoIP auto fingerprint matching

Time Randomization:
- All delays use normal distribution randomization
- Typing speed 50-150ms/char
- Request interval 30s-2min random
- Field switch delay 0.3-0.8s

Stop-Loss and Recovery:
- Single failure → Cooldown 15 mins
- Consecutive 3 failures → Global pause 3-8 mins
- Captcha trigger → Pause 10 mins
- Auto resume after pause, continue queue
```

### 2. Data Rules
```
⚠️ Discharge Date Limit: Must be within past 12 months!
   - E.g., Today is 2025-12-24, valid range = 2024-12-24 ~ 2025-12-24
   - Out of range will show "Invalid discharge date"
   - Code auto-calculates: Current date minus 1-11 months random

Name/DOB/Branch: Use BIRLS real data
Discharge Date: Dynamic random generation (Past 1-11 months)
Email: Temp email, receiving two emails:
  1. ChatGPT Verification Code (6 digits/letters)
  2. SheerID Verification Link (https://services.sheerid.com/verify/...)
```
